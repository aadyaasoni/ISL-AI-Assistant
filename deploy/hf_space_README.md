# ISL Communication Assistant

A constrained 11-gloss Indian Sign Language recognition prototype with a browser camera, deterministic text responses, a skeleton landmark animation, and text-to-sign lookup. This is not a general-purpose or continuous ISL translator.

Camera access requires the direct HTTPS `*.hf.space` URL. See the upstream repository README for model evaluation, setup, and limitations.
