# Skeleton Clip Attribution

The files in `avatar/clips/` are stick-figure animation data derived from the repository's extracted landmark samples for the **INCLUDE-50 Indian Sign Language dataset** (Adjectives category). Each clip selects one sample per available gloss and stores downsampled, normalized landmark coordinates; raw video is not copied into the clip files.

The repository documentation identifies INCLUDE (IIT Bombay) but does **not** include the dataset's license text or establish redistribution rights for derivative landmark data. Verify the dataset license and attribution requirements before redistributing these generated clips. No license is claimed here.

This is a lightweight 2D skeleton visualization, not a rigged 3D avatar. A rigged model and sign animations remain future work and must not be added until their source, license, and redistribution terms are verified.
